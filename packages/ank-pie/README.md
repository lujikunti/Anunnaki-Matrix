# ANK PIE

Shared governed-agent manifests for Anunnaki Matrix products.

## ANK Growth

`agents/ank-growth-v1.json` is the canonical pull-first Growth & Distribution worker. Product repositories mirror the manifest into their live ANK PIE control policies because MN and GC currently maintain separate Supabase control-plane instances.

The agent may research, draft, map channels, qualify inbound demand and analyse attribution autonomously. External messaging and public publication require human approval. Cold email and cold DMs are disabled by design.

Run:

```bash
npm test
```

## ANK Operator profiles

Operator profiles are a naming, packaging and training layer over ANK PIE; they are **not** another agent runtime or trust system. `operators/operator-profiles-v1.json` maps familiar corporate roles to existing governed agents. All capability trust, promotion, demotion and execution authority remain with `ANK_AGENT_APPRENTICESHIP_V1` and the existing PIE worker allowlists.

The Revenue Operator reuses `ank-growth`. Its additional commercial capabilities begin as training-only and cannot execute merely because they appear in the profile or agent manifest.
